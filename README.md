# JavaScript Exercises

Exercises from my frontend development course, organized in the order I
completed them. Each folder is a standalone exercise you can open directly
in the browser.

| #   | Exercise                                        | Demo                                                                        | Topics                                                                                                                                                                                                 |
| --- | ----------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 01  | [JS Functions](./01-js-functions)               | [Live](https://eng-mohammadi.github.io/js-exercises/01-js-functions/)       | Functions, `for` and nested loops, conditionals, the `%` operator, reading input with `getElementById`, `Number()` conversion, `window.alert`, inline `onclick` handlers, basic input validation, SCSS |
| 02  | [DOM Login & Register](./02-dom-login-register) | [Live](https://eng-mohammadi.github.io/js-exercises/02-dom-login-register/) | Building the UI with the DOM API (`createElement`, `setAttribute`, `classList`, `appendChild`, `removeChild`), click event listeners, switching between views, dynamic inline styles, SCSS             |

## Notes

- Exercise 01 draws the triangle with `document.write`, as the exercise required. Since `document.write` replaces the page content once the page has loaded, reload the page to use the other buttons again.
- Exercise 02 builds its whole interface from JavaScript, so the page stays empty if JavaScript is disabled.

For a larger project built step by step with what I learned in the course, see
[food-ordering-app](https://github.com/eng-mohammadi/food-ordering-app). -->
